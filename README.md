# Eternal Realm — Rune Resonance
Fullscreen 2D pixel action RPG prototype (HTML Canvas, CSS, vanilla JS).

## Controls
- PC: WASD / Arrow, Space attack, Q Ember, R Frost, Shift Dash, 1 potion, F interact, Esc pause.
- Mobile: directional pad on the left; attack, magic, dash, potion on the right.

## Mechanics
Melee combat, Ember/Frost projectiles, Rune Resonance combo burst, enemy AI (Slime/Wisp/Brute), quest from Elder Rowan, treasure chest, healing shrine, XP/level progression, gold, shards, autosave, and monster respawn.

Open index.html or run python -m http.server 8000. Single-player prototype; online multiplayer is not implemented.
